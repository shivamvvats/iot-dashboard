# 🚀 Smart IoT Dashboard

A modern IoT dashboard that simulates real-time sensor data with a clean UI and live graph visualization.

## 🔥 Features
- 🌡 Real-time Temperature Monitoring
- 🔥 Fire Risk Detection
- 💧 Humidity Tracking
- 📊 Live Updating Graph (Chart.js)
- 💎 Modern Glass UI Design

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript
- Chart.js
